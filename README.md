# 🚗 Установка приложений на Geely Cityray (Boyue Cool, G426)

📖 English version: **[README_EN.md](README_EN.md)**

**Без root. Без перепрошивки. Без риска для машины.**

На новой прошивке Cityray (Android 11, `user`-сборка) обычная установка приложений через ADB заблокирована. Этот набор обходит блокировку легальным способом — обращается к системному установщику напрямую. Приложения ставятся **навсегда** и переживают перезагрузку.

**Кому подойдёт:** владельцам Geely Cityray / Boyue Cool (G426) на новой прошивке — той, где справа вверху осталась только иконка Bluetooth, а `adb install` падает с ошибкой `User build type restriction prevents installing`.

### 📦 Что здесь лежит

| Компонент | Что делает |
|---|---|
| **`tools/GeelyTool.exe`** | Готовит флешку (FAT32 + файл `svlog.flag`) и считает 6-значный код активации ADB. Без него ADB на новой прошивке не открыть |
| **`helper/Installer.java`** + `installer.dex` | Ядро обхода: ставит APK через системный `PackageInstaller` API, минуя заблокированную команду `pm` |
| **`install.bat`** + `scripts/` | Установка всех APK из папки `apks/` одной кнопкой |

Как именно устроен обход, что пробовали и почему остальное не работает — подробно в **[DETAILS_TECH.md](DETAILS_TECH.md)**.

> ⚠️ Всё это вы делаете со **своей** машиной и на свой страх и риск. Здесь нет ничего, что ломает магнитолу — мы ничего не пишем в системную память, только устанавливаем приложения.

---

## 🧰 Что понадобится

| Что | Пример / примечание |
|---|---|
| Ноутбук с **Windows** | 10 или 11 |
| **USB-флешка** | от 8 ГБ (данные с неё сотрутся) |
| **Кабель USB-A → USB-C** | обычный USB (тип A) в ноутбук, **Type-C в машину**. Нужен для связи ноут↔магнитола |
| Файлы приложений **`.apk`** | те, что хотите поставить. Где взять — см. **[ИСТОЧНИКИ.md](ИСТОЧНИКИ.md)** |

---

## ✅ Шаг 0. Установить ADB (делается один раз)

1. Нажмите **Пуск**, напечатайте `PowerShell`, откройте его.
2. Вставьте команду и нажмите Enter:
   ```
   winget install Google.PlatformTools
   ```
3. Закройте это окно PowerShell. Всё.

---

## 🔓 Шаг 1. Открыть ADB на магнитоле

**1.1. Подготовить флешку.**
- Вставьте флешку в ноутбук.
- Откройте `tools\GeelyTool.exe` → на запрос прав нажмите **«Да»**.
  *(Если выскочит синее окно «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».)*
- Нажмите кнопку **«1. Подготовить флешку»** → подтвердите. Флешка готова.

**1.2. В машине.**
- Откройте приложение **«Телефон»**, наберите `*#32279` — откроется инженерное меню.
- Зайдите: **CUSTOMIZATION → ADB → верхний переключатель Adb Switch → Open**.
- На экране появится **QR-код** и поле для кода.

**1.3. Снять код.**
- Вставьте флешку в **USB-порт машины**.
- Подождите, пока на экране появится **«Android — OK, QNX — OK»**.
- Выньте флешку. **❗ QR-код НЕ закрывайте!**
- Вставьте флешку обратно в ноутбук.
- В `GeelyTool.exe` нажмите **«2. Показать код»** — покажет **6 символов** (регистр важен!).
- Введите эти 6 символов в поле под QR на экране машины → нажмите **левую кнопку** под QR.
- QR закроется — **ADB открыт!** 🎉

---

## 🔌 Шаг 2. Подключить ноутбук к машине

Соедините ноутбук и магнитолу **кабелем USB-A → USB-C**: обычный USB (тип A) в ноутбук, **Type-C в USB-порт машины**.

---

## 📦 Шаг 3. Положить приложения

Скопируйте нужные файлы **`.apk`** в папку **`apks`** (она рядом с `install.bat`).

> Где взять приложения (RuStore, паки Geely-модов и т.д.) — всё со ссылками в **[ИСТОЧНИКИ.md](ИСТОЧНИКИ.md)**. Чужие APK мы в репозиторий не кладём — только ссылки, откуда скачать.

---

## ▶️ Шаг 4. Установить

Двойной клик по **`install.bat`**. Дождитесь надписи `ИТОГО: OK=... FAIL=0`. Готово!

Приложения появятся в лаунчере **GLauncher / GInputBridge** (долгий тап по значку мультимедиа «нотка» в доке → значок «−» → синий значок → там все приложения).

---

## ❗ Важно помнить

- ✅ Приложения ставятся **навсегда**, перезагрузка их не удаляет.
- 🔁 **ADB закрывается после каждой перезагрузки** магнитолы. Снова открывать (Шаг 1) нужно **только чтобы поставить новые** приложения.
- ⛔ Заменить **системные** приложения (с тем же именем пакета, напр. штатные «Настройки») так нельзя.

---

## 🆘 Если что-то не так

| Проблема | Решение |
|---|---|
| `ADB не найден` | Сделайте Шаг 0, закройте и снова откройте окно |
| `Магнитола не подключена` | Проверьте кабель (**USB-A → Type-C, с передачей данных**) и что ADB открыт (Шаг 1) |
| Флешка не форматируется | Запускайте `GeelyTool.exe` от имени администратора (он сам просит) |
| Код не подходит | Регистр важен. Не закрывали ли QR? Если закрыли — откройте заново (Шаг 1.2) и снимите новый код |
| `FAIL` при установке | Возможно, это системное приложение-замена — такие не ставятся |
